# Projektstruktur: maurer-events
Pfad: maurer-events
Stand: 2026-08-30
Typ: Next.js 16 App Router (i18n mit next-intl) - Event-Management Plattform für Maurer Events
Deployment: Cloudflare Workers via OpenNext (@opennextjs/cloudflare) — **FUNKTIONIERT**

## Kurzbeschreibung
Vollständige Event-Management Plattform für "Maurer Events" (Veranstaltungsagentur). Next.js 16 mit App Router, next-intl für DE/EN i18n. Features: Öffentliche Website (Events, Galerie, Reservation, Karriere), Admin-Bereich (Event-CRUD, Scanner-Check-in, Tisch-Zuweisung, Warteliste, Druck-Layouts), Stripe Payment Integration, Vercel Blob Storage für Bilder, Neon PostgreSQL + Drizzle ORM, Rive Animationen, QR-Scanner für Check-in, PDF-Ticket Generierung, Resend E-Mails, Cron Jobs für Cleanup.
**Deployment:** Cloudflare Workers via OpenNext (@opennextjs/cloudflare v1.20.4). Build auf Linux (keine Windows-Pfade). Single Worker Function (handler.mjs ~2.6 MB gzipped) + Assets (4.1 MB gzipped). Middleware gebündelt. Images Binding für @vercel/og WASM. D1/KV nicht genutzt (Neon DB direkt via Hyperdrive-kompatiblen Treiber).

## Deployment Commands (OpenNext / Cloudflare Workers)
```bash
# Lokale Entwicklung (Next.js Dev Server)
npm run dev                      # next dev (Port 3000)

# OpenNext Build für Cloudflare
npm run build:worker             # opennextjs-cloudflare build → .open-next/

# Lokale Preview (Cloudflare Simulator)
npm run preview                  # opennextjs-cloudflare preview (Port 8787)

# Type Generation
npx wrangler types               # worker-configuration.d.ts

# Deploy (Dry-Run zur Validierung)
npm run deploy -- --dry-run      # wrangler deploy --dry-run

# Production Deploy
npm run deploy                   # wrangler deploy

# Logs & Debugging
npx wrangler tail                # Live Logs
```

## Environment / Secrets (Production - via wrangler secret put)
```bash
wrangler secret put DATABASE_URL           # Neon PostgreSQL Connection String
wrangler secret put STRIPE_SECRET_KEY      # Stripe Secret Key
wrangler secret put STRIPE_WEBHOOK_SECRET  # Stripe Webhook Signing Secret
wrangler secret put RESEND_API_KEY         # Resend E-Mail API Key
wrangler secret put BLOB_READ_WRITE_TOKEN  # Vercel Blob Token (für Uploads)
wrangler secret put NEXTAUTH_SECRET        # NextAuth / Session Secret
wrangler secret put ADMIN_EMAIL            # Admin Login E-Mail
```
